# Olive & Ember — Mediterranean Dining

Olive & Ember is a Mediterranean-inspired restaurant website designed to create a warm, elegant, and welcoming digital dining experience. The project combines editorial typography, earthy colors, atmospheric photography, and responsive layouts.

## Live Demo

Coming soon — the website will be deployed using GitHub Pages.

## Features

- Responsive layouts for desktop, tablet, and mobile.
- Restaurant story and brand presentation.
- Signature menu section.
- Food and restaurant photography gallery.
- Reservation form with client-side validation.
- Mobile navigation and interactive elements.
- Scroll animations and micro-interactions.
- Accessibility and SEO considerations.
- Custom favicon and cohesive visual design.

## Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if you haven't already.
4. Open `index.html` and select **Go Live**.
5. View the website in your browser.

## Reservation Form

The reservation form currently demonstrates client-side interaction and validation. Real reservations require a connected backend or reservation service.

## Design Direction

The visual identity is inspired by Mediterranean dining, using warm ivory, deep olive, terracotta, and sandstone tones. Editorial serif typography is paired with a clean sans-serif body font to create a premium restaurant aesthetic.
